# Blog Preview Card — React

A responsive blog preview card built with React as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

This project is a React implementation of my original HTML/CSS solution.

## Screenshot

<img src="./src/assets/screenshot-%202026-11-09%20at%2022.20.26.png" alt="React Blog Preview Card screenshot" width="400">

## Built With

- React
- JavaScript (JSX)
- CSS3
- Vite
- Flexbox
- Responsive Media Queries

## Features

- Responsive layout for desktop and mobile
- Custom Figtree variable font
- Interactive hover and focus states
- React functional component
- Local SVG and WebP assets

## What I Learned

This challenge helped me practice migrating an existing HTML/CSS implementation to React.

Key learning outcomes:

- Converting HTML elements into JSX
- Using `className` instead of `class`
- Creating and exporting React functional components
- Importing local images into React components
- Reusing existing CSS in a React application
- Maintaining responsive layouts with CSS media queries

## Getting Started

Clone the repository:

```bash
git clone https://github.com/glovatskiy/frontend-mentor-challenges.git
```

Navigate to the project:

```bash
cd frontend-mentor-challenges/react/blog-preview-card-main
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

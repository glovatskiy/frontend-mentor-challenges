# Blog Preview Card — React Native

A mobile blog preview card built with React Native and Expo as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

This project is a React Native implementation of my original HTML/CSS and React solutions.

## Screenshot

<img src="./assets/Screenshot_20261110_021244_Expo%20Go.jpg" alt="Blog Preview Card running in Expo Go" width="300">

## Built With

- React Native
- JavaScript (JSX)
- Expo
- React Native StyleSheet
- Flexbox
- Expo Font

## Features

- Mobile-friendly card layout
- Custom Figtree font
- Local PNG and WebP images
- Card borders, rounded corners, and hard shadows
- Reusable React Native component
- Native styling using `StyleSheet.create()`

## What I Learned

This challenge helped me practice converting an existing web interface into a native mobile application using React Native.

Key learning outcomes:

- Using `View`, `Text`, and `Image` instead of HTML elements
- Styling components with `StyleSheet.create()`
- Understanding differences between CSS and React Native styling
- Loading custom TTF fonts with `expo-font` and `useFonts`
- Importing and displaying local images
- Building layouts using React Native Flexbox
- Organizing an application into reusable components

## Getting Started

Clone the repository:

```bash
git clone https://github.com/glovatskiy/frontend-mentor-challenges.git
```

Navigate to the project:

```bash
cd frontend-mentor-challenges/react-native/blog-preview-card
```

Install dependencies:

```bash
npm install
```

Start Expo:

```bash
npx expo start
```

Open the application using Expo Go on your mobile device.

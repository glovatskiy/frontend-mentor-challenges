# Social Links Profile — HTML & CSS

A social links profile card built with HTML5 and CSS3 as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

This project focuses on creating a clean, centered interface using Flexbox, semantic HTML, custom typography, and reusable CSS styles.

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Box Model
- Custom Inter Variable Font
- Git & GitHub

## Features

- Dark-themed social profile card
- Centered layout using CSS Flexbox
- Profile avatar with rounded borders
- Custom typography using the Inter variable font
- Vertically arranged social links
- Full-width clickable link areas
- Clean and consistent spacing

## What I Learned

This challenge helped me strengthen my understanding of HTML and CSS fundamentals through independent implementation and debugging.

Key learning outcomes:

- Using nested Flexbox containers to control page layout
- Centering elements horizontally and vertically
- Understanding the difference between `justify-content` and `align-items`
- Using `min-height: 100vh` to create full-height page layouts
- Positioning a footer at the bottom using `flex: 1`
- Understanding default browser margins and padding
- Styling anchor elements to make entire link areas clickable
- Loading custom variable fonts with `@font-face`
- Organizing CSS for readability and maintainability

## Getting Started

Clone the repository:

```bash
git clone https://github.com/glovatskiy/frontend-mentor-challenges.git
```

Navigate to the project:

```bash
cd frontend-mentor-challenges/html-css-js/social-links-profile-main
```

Open `index.html` in your browser.

No additional dependencies or build tools are required.

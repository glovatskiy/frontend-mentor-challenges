# QR Code Component — HTML & CSS

A responsive implementation of the [Frontend Mentor QR Code Component challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H), built using **HTML5 and CSS3**.

## Overview

This project recreates the QR Code Component design provided by Frontend Mentor using plain HTML and CSS.

The objective was to practice fundamental frontend development concepts, including HTML structure, CSS styling, Flexbox alignment, typography, and responsive layouts.

This is the first implementation of the QR Code Component in my Frontend Mentor learning journey. I subsequently recreated the same design using React and React Native to strengthen my understanding of how frontend concepts transfer between technologies.

## Getting Started

### Prerequisites

A modern web browser.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/glovatskiy/frontend-mentor-challenges.git
```

**2. Navigate to the project**

```bash
cd frontend-mentor-challenges/html-css-js/qr-code-component-main
```

**3. Run the project**

Open `index.html` in your browser.

No installation or build tools are required.

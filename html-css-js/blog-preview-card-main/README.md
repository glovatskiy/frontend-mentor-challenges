
# Blog Preview Card — HTML & CSS

A responsive implementation of the [Frontend Mentor Blog Preview Card challenge](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS), built using **HTML5 and CSS3**.

## Overview

This project recreates the Blog Preview Card design provided by Frontend Mentor using plain HTML and CSS.

The objective was to practice translating a Figma design into a responsive webpage, focusing on accurate spacing, typography, Flexbox layouts, and CSS styling.

The implementation does not require JavaScript, frameworks, or external UI libraries.

## Getting Started

### Prerequisites

A modern web browser.

### Installation

**1. Clone the repository**

~~~bash
git clone https://github.com/glovatskiy/frontend-mentor-challenges.git
~~~

**2. Navigate to the project**

~~~bash
cd frontend-mentor-challenges/html-css-js/blog-preview-card-main
~~~

**3. Run the project**

Open `index.html` in your browser.

No installation or build tools are required.

## What I Learned

### HTML Structure

- Structuring content using semantic HTML elements
- Organizing a card into logical content sections
- Using descriptive image alternative text
- Linking external stylesheets

### CSS Flexbox

- Centering elements horizontally and vertically
- Understanding `flex-direction`, `justify-content`, and `align-items`
- Managing spacing between elements with `gap`
- Understanding how `flex-shrink` affects image dimensions
- Working with nested Flexbox containers

### Responsive Design

- Creating responsive layouts using CSS media queries
- Adjusting card dimensions and typography for mobile screens
- Understanding CSS viewport dimensions versus physical screen resolution
- Maintaining image proportions with `object-fit: cover`

### Typography and Styling

- Loading local TrueType variable fonts using `@font-face`
- Applying multiple font weights from a single variable font
- Managing default browser margins and element spacing
- Understanding `box-sizing: border-box`
- Creating hard-offset shadows using `box-shadow`
- Matching colors, spacing, and typography to Figma specifications
